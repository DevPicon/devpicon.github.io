Before you install

  • A Mac with Apple silicon. The DMG for version 0.1.0-alpha.5 is built for ARM64.
  • A local Android SDK. Install Android Emulator, Android SDK Platform-Tools and Android SDK Command-line Tools (latest).
  • JDK 17 or later. The SDK command-line tools require Java.

Install with Homebrew

brew install --cask devpicon/tools/android-emulator-hub

This release appears on your Mac as Android Emulator Hub.

To start your first emulator, select an existing virtual device or create one in the hub. You can download an Android system image from the app if you need one.
